- letter U_ — are projects from courses on Udemy;

- letter FEM_ — are projects from Front-end Mentor;
- letter H_ — are primitive-design (very upsetting) projects, I've worked on At Home. short intensive to get familiar with Web design;

- letter -JS - are related to Frontend  (JavaScript);
- letter -N - are related to Backend  (Node.js);
- letter -PY - are related to Python code practice
- letter -RE - are related to React.js/React.ts SPA projects
